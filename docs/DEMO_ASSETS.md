# Demo assets

The repository includes three anonymized portfolio demos built entirely with fake data:

- `assets/demo-workflow.gif` — edit processing, timestamping, fuzzy normalization, required-field population and formatting.
- `assets/demo-wait-state.gif` — background waiting-state escalation after the configured short-wait threshold.
- `assets/demo-report-export.gif` — report aggregation, XLSX export and creation of the generated file in Google Drive.

The demos intentionally avoid real patient names, staff names, organization names, folder IDs, email addresses, PINs and private configuration values.

If additional screenshots or GIFs are added later, keep them anonymized and use fake data only.
